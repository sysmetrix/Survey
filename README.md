# 청소년 사업 설문 분석 · 결과평가 보고서 도구 (v5)

부천여성청소년재단 직원이 설문 엑셀을 올리면 **통계 분석 → 성과지표 달성 판정 → 개조식 분석글·그래프가 들어간 한글(HWPX) 붙임 보고서 → 발표 슬라이드**까지 만드는 웹 도구입니다.
모든 처리는 브라우저 안에서만 이루어지며 설문 파일은 외부로 전송되지 않습니다.

- 접속: https://sysmetrix.github.io/Survey/
- 이전 버전(v4.3): https://sysmetrix.github.io/Survey/legacy/v4.html

## 직원용 사용 방법

1. **불러오기** — 엑셀(.xlsx/.xls) 또는 CSV(최대 50MB)를 끌어다 놓습니다. 처음이라면 *만족도 조사 템플릿* / *사전·사후 조사 템플릿*을 내려받아 입력하세요. 샘플 6종(구글폼·네이버폼·사전사후·회고식·한 시트 사전사후·7점 척도+NPS)으로 먼저 체험할 수 있습니다.
   - 구글폼·네이버폼·타입폼·탈리폼에서 내려받은 원본 파일도 그대로 됩니다. '전혀 아니다~매우 그렇다', '매우 불만족~매우 만족', 'Strongly disagree~Strongly agree' 같은 보기 문구를 **숫자로 바꾸지 않아도** 자동으로 점수화하며, 타임스탬프·응답 ID 같은 메타 열은 분석에서 뺍니다.
   - '보통'이 없는 4단계 보기는 4점 척도로 판정합니다. 응답이 적어 4점/5점이 불분명하면 경고합니다.
   - 사전에 없는 문구(예: '완전 좋아요')는 데이터 설정의 **보기 점수**에서 문구별 점수를 한 번 지정하고 *같은 보기를 쓰는 문항에 모두 적용*하면 됩니다.
   - 한 파일에 `사전`·`사후` 시트가 있으면 ID로 같은 응답자를 연결합니다. 한 시트에서 `사전_문항`·`사후_문항`(회고식은 `이전_`·`현재_`) 형식도 인식합니다. 헤더에 `(역문항)`·`(R)`이 있으면 역채점합니다.
   - 긴 문항명도 자르지 않습니다(표·그래프에서 줄을 바꿔 전체 표시). `(필수)`·`[필수]` 표시는 자동으로 뺍니다.
2. **데이터 설정** — 자동 판별된 문항 역할(척도·응답자 특성·주관식 등), 척도 범위, 역문항, 영역(하위척도), 사전·사후 짝, 불성실 응답 제외 여부를 확인합니다.
3. **성과지표 (선택)** — *빠른 추가*(만족도 80점, 긍정응답률, NPS, 사전·사후 향상, 향상자 비율, 참여 인원 등)로 지표를 넣고 목표값만 고치면 실적·달성률·판정이 즉시 계산됩니다. 건너뛰어도 보고서는 만들어집니다.
   - **사업정보·논리모형은 선택 항목**으로 접혀 있습니다. 펼쳐서 입력하면 보고서에 사업 개요·논리모형 표·목표별 달성 평가가 추가됩니다.
4. **분석 결과** — 성과지표 달성, 사전·사후 변화(대응표본 t / Wilcoxon, 효과크기, 향상자 비율), 만족도(100점 환산·긍정응답률·NPS·IPA), 응답자 특성별 차이, 주관식 주제·대표 의견, 자료 품질을 확인합니다.
5. **보고서** — 자동 작성된 문장을 클릭해 고치고(✕ 빼기, ↺ 되돌리기), 필요한 장만 선택한 뒤 **한글(HWPX) 내려받기**. 인쇄/PDF, 워드·구글문서 붙여넣기용 복사도 됩니다.
   - 직접 고친 문장의 근거 수치가 나중에 바뀌면(데이터 설정 변경 등) 문장 옆에 **근거 변경** 표시가 붙습니다.
   - *프로젝트 파일 저장*을 하면 문항 설정·사업정보·지표·문장 수정·문서 서식이 저장되어 다음 차수 조사에 그대로 적용됩니다(원자료는 선택 시에만 포함).
   - 화면 위쪽 얇은 도구모음에서 **사용법**, **한글 문서 서식**(글꼴·크기·줄 간격), **장 이동**, **확대·축소**(화면 미리보기만 바뀌며 내려받는 파일 크기는 그대로), 한글·인쇄·복사 바로가기를 씁니다. 표시할 장 선택·프로젝트 저장 같은 설정은 왼쪽 사이드바에 있습니다.
6. **발표** — 상단 *발표* 버튼으로 핵심 결과를 16:9 슬라이드로 바로 보여 줍니다.
   - 슬라이드마다 결론을 말하는 제목 하나와 그에 맞는 그래프 하나: 표지 → 한눈에 보기 → 성과지표 달성 → 사전·사후 변화 → 만족도 순위 → 응답 분포 → 추천의향 → 개선 우선순위(IPA) → 집단 비교 → 참여자 목소리 → 종합 평가 → 마무리
   - 단축키: `→`/`Space` 다음, `←` 이전, 숫자+`Enter` 이동, `O` 개요(슬라이드 숨기기), `N` 발표자 노트(근거 수치·경과 시간), `F` 전체화면, `B` 화면 가리기, `T` 밝은/어두운 무대, `P` 발표 자료 내려받기, `Esc` 끝내기
   - **발표 자료 내려받기**는 세 가지입니다. *PDF로 저장*은 슬라이드당 한 쪽인 인쇄본(종이·메일용), *HTML 파일로 저장*은 **파일 하나로 끝나는 발표본**, *PPTX로 저장*은 **PowerPoint에서 계속 고쳐 쓸 수 있는 편집 가능한 파일**(화면에 보이는 위치·글자·색·이미지가 실제 도형·텍스트 상자로 그대로 들어감)입니다. HTML 파일은 인터넷도 이 도구도 없는 PC에서 두 번 눌러 열면 지금 화면 그대로 넘기며 발표할 수 있습니다(같은 단축키·개요·발표자 노트·무대 밝기·전체화면, 거기서 다시 PDF 인쇄도 가능). 숨긴 슬라이드는 모두 빠집니다.
   - 발표 도구모음의 **슬라이드 편집**(연필 아이콘)에서 문구를 직접 고치고, *자유배치로 바꾸기*를 누르면 요소 위치·크기·회전을 드래그로 조절하거나 텍스트·목록·표·이미지·도형을 새로 추가할 수 있습니다. 빈 슬라이드 추가·삭제·순서 변경도 이 화면에서 합니다. 자유배치로 꾸민 내용도 되돌리기·버전 복원·발표 자료 내려받기에 그대로 반영됩니다.

### 한글(HWPX) 보고서 서식
- **표**: 글자처럼 취급하지 않고 *여러 쪽 지원 — 나눔*으로 만들어, 긴 표가 쪽 경계에서 이어지고 다음 쪽에 제목 줄이 반복됩니다. 열이 12개를 넘는 표는 첫 열을 유지한 채 나눕니다. 그래프는 한 덩어리로 옮겨지도록 글자처럼 취급합니다.
- **글꼴**: 보고서 화면의 *한글 문서 서식*에서 휴먼명조(기본)·맑은 고딕·나눔고딕·KoPub돋움체·Noto Sans KR·Pretendard GOV·직접 입력 중에서 고르고, 글자 크기(10~15pt)·줄 간격(150~180%)을 정합니다. 설정은 미리보기에 바로 반영되며 *이 PC에 글꼴이 있는지 확인*으로 설치 여부를 볼 수 있습니다. Windows·한글·글꼴 배포판에 따라 달라지는 패밀리명과 영문 설치명도 함께 확인합니다.
  - 휴먼명조(공문서형 조합)는 큰 제목에만 `HY헤드라인M`을 쓰고, 본문·표·캡션과 굵은 글씨는 모두 `휴먼명조`(굵게)로 씁니다.
  - HWPX에는 글꼴 이름만 들어갑니다. 받는 PC에 글꼴이 없으면 함초롬 글꼴로 대신 표시되도록 대체 글꼴을 함께 기록합니다(Pretendard는 `GOV`/`GOV Variable` 설치 이름을 서로 대체). KoPub돋움체의 굵은 글자는 `KoPub돋움체 Bold` 글꼴을 씁니다.
- **이모지**: 웹에서는 보이지만 한글 글꼴에 없어 네모(□)로 깨지는 이모지는 한글에서 보이는 기호·글자로 바꿉니다. 예) ✅→√, ❌→×, ⚠️→※, ⭐→★, ❤️→♥, 1️⃣→①, 😊→^^, 😢→ㅠㅠ, 👍→(최고). 대응표에 없는 그림 문자는 지웁니다.

### 작업 내역 (자동 저장 · 되돌리기 · 버전 관리)
- 문항 설정·성과지표·사업정보·문장 수정·보고서 서식이 바뀌면 **2~3초 뒤 이 브라우저에 자동 저장**됩니다(같은 내용은 다시 저장하지 않고, 5분 안의 자동 저장은 한 버전으로 합칩니다). 파일을 불러올 때와 한글 파일을 내보낼 때도 기록합니다.
- **되돌리기 `Ctrl+Z` / 다시 실행 `Ctrl+Y`**(상단 화살표 버튼)로 방금 한 변경을 취소할 수 있습니다.
- 상단 시계 버튼(**작업 내역**)에서 설문별 버전 타임라인을 보고, *지금과 비교*로 무엇이 바뀌었는지 확인하고, *이 버전으로 복원*할 수 있습니다(복원 직전 상태도 자동 보관). 중요한 버전은 이름을 붙이고 *고정*하면 자동 정리에서 제외됩니다.
- 원자료(응답 데이터)는 기본적으로 저장하지 않습니다. *버전 저장*에서 선택하면 **비밀번호로 암호화(AES-256-GCM, PBKDF2 310,000회)** 해 함께 보관할 수 있고, 비밀번호는 어디에도 저장되지 않습니다. 원자료가 없는 버전은 같은 설문 파일을 올리면 설정이 그대로 적용됩니다.
- 자동 저장 보관 개수(10/30/100개)·기간(30/90/365일), 저장 공간 사용량, *영구 보관 요청*, **백업 파일 받기/가져오기**, 모든 내역 삭제를 제공합니다. 여러 창을 열어도 내역이 서로 동기화됩니다.
- 이전 버전(v4.3)이 브라우저에 남긴 분석 이력(원자료 포함 가능)을 찾으면 내려받기·삭제를 안내합니다. **공용 PC에서는 작업 후 내역을 삭제하세요.**

### 화면 테마 · 앱 설치(PWA)
- 오른쪽 위 테마 버튼으로 *시스템 설정 → 밝은 화면 → 어두운 화면*을 바꿉니다. 보고서 미리보기와 HWPX는 인쇄 문서이므로 항상 흰 종이 기준입니다.
- 크롬·엣지 주소창의 설치 아이콘(또는 상단 *앱 설치*)으로 설치하면 바탕화면·시작 메뉴에서 창으로 열리고, 한 번 접속한 뒤에는 **인터넷 없이도** 동작합니다. 설치한 앱은 탐색기에서 .xlsx/.csv 파일의 *연결 프로그램*으로도 열 수 있습니다.
- 새 버전이 배포되면 오른쪽 아래에 *지금 업데이트* 알림이 뜹니다. 현재 버전은 상단에 `v5.26.0`으로 표시됩니다.
- 상단의 톱니바퀴에서 기관·부서명과 담당자명(보고서·발표 표지에 자동 반영), 화면 테마, 자동 저장, 자동 버전 수와 보관 기간을 브라우저별로 설정하고, *…화면으로* 버튼으로 직전 화면에 돌아갈 수 있습니다. 화면이 이전 버전으로 보이면 *캐시 비우고 새로고침(Ctrl+F5)*으로 앱 파일만 다시 받으며 작업 내역과 설정은 유지됩니다.

### 보고서 구성(해당 자료가 있는 장만 자동 포함)
요약 → Ⅰ 사업 개요·논리모형 → Ⅱ 조사 개요·응답자 특성 → Ⅲ 성과지표 달성 현황 → Ⅳ 사전·사후 성과 변화 → Ⅴ 만족도 분석 → Ⅵ 응답자 특성별 비교 → Ⅶ 주관식 응답 분석 → Ⅷ 종합 평가·개선 방안·차년도 목표(안)·유의사항 → 부록(응답 분포, 전체 검정 결과, 산식)

### 판정 기준(기본값)
- 달성률 = 실적 ÷ 목표 × 100(하향 지표는 {1 − (실적−목표) ÷ |목표|} × 100) · 100% 이상 달성, 90% 이상 대체로 달성, 그 미만 미달성
- 종합 등급 = (달성 + 대체로 달성×0.5) ÷ 측정 지표 수 · 80% 이상 우수, 60% 이상 보통
- 100점 환산 = (평균 − 최소점) ÷ (최대점 − 최소점) × 100 · 85 이상 매우 높음, 75 이상 높음, 60 이상 보통 이상
- **100점 환산 기준**: 데이터 설정 단계(분석 전)에서 *반올림 전 평균으로 환산*(기본, 정확) 또는 *반올림 후 평균으로 환산*(표에 적힌 소수 둘째 자리 평균으로 직접 환산한 값과 일치, 예: 4.37점 → 84.25)을 고릅니다. 이 파일에서 두 기준이 얼마나 달라지는지 예시와 문항 수로 보여주며, 상단 톱니바퀴 *로컬 설정*에서 언제든 바꿀 수 있습니다. 선택한 기준은 정렬·수준 판정·성과지표 판정·차트·발표 자료에 모두 적용되고, 사전사후 변화량·효과크기·검정 같은 통계는 항상 원자료로 계산합니다.

### 보안·개인정보
- 파일 분석·보고서 생성·작업 내역은 모두 브라우저 안에서 처리하며 외부 서버·API로 보내지 않습니다(CSP `connect-src 'self'`, 외부 스크립트 없음, 리퍼러 전송 안 함).
- 원자료는 기본적으로 어디에도 저장하지 않으며, 보관을 선택한 경우에만 비밀번호 암호화합니다. 주관식 인용문의 전화번호·이메일 형태는 자동으로 가립니다.
- 프로젝트·백업 파일은 크기 제한과 형식 검사를 거쳐 읽고, 프로토타입 오염 키(`__proto__` 등)는 제거합니다. 한글 파일에 들어갈 수 없는 제어 문자는 지웁니다.
- 로컬 사본 라이브러리(PapaParse·SheetJS·JSZip)는 SHA-256 해시를 테스트로 고정해 변조를 검사합니다. 취약점 제보: `.well-known/security.txt`

## 개발자용

빌드 없이 ES 모듈로 동작합니다(GitHub Pages 정적 배포). 파일을 더블클릭(file://)하면 동작하지 않으므로 로컬에서는 웹서버로 엽니다.

```bash
python -m http.server 8000          # http://127.0.0.1:8000/
npm install                          # 테스트용 @xmldom/xmldom
npm test                             # 통계(R 기준값)·모델·분석·평가·보고서·HWPX·작업 내역·화면·규칙·PWA·무결성 테스트
node tools/make-samples.mjs          # samples/ 6종 재생성(시드 고정)
node tools/build-sample-reports.mjs  # 샘플 → out/reports/*.hwpx (+구조 검증)
node tools/validate-hwpx.mjs out     # HWPX 구조 검증(mimetype·XML·ID 참조·표 격자) — npm run validate
node tools/validate-pptx.mjs out     # PPTX 구조 검증(Content_Types 커버리지·XML·관계 참조 무결성) — npm run validate:pptx
powershell -File tools/hwp-verify.ps1 -Dir out/reports   # 설치된 한글로 열기·PDF 저장 검증
node tools/browser-e2e.mjs           # Edge 헤드리스: 화면·HWPX·되돌리기·작업 내역·글꼴·다크·발표·PDF·모바일·오프라인(웹서버 필요)
node tools/build-sw.mjs              # ★ 파일을 고친 뒤 배포 전 필수: 서비스워커 사전 캐시 목록·리비전 갱신 (npm test 가 최신 여부 검사)
node tools/make-icons.mjs            # icons/*.svg → PWA 아이콘 PNG
```

- 로컬 개발 서버(localhost·127.0.0.1)에서는 수정 사항이 캐시에 가려지지 않도록 서비스워커를 등록하지 않습니다. PWA를 시험할 때만 `http://127.0.0.1:8000/?sw=1` 로 엽니다.
- 버전을 올릴 때는 `js/admin/releases.js`의 최신 항목, `js/main.js`의 `APP_VERSION`, `js/ui/history/version.js`, `package.json`·`package-lock.json`, `index.html`의 `?v=`를 함께 바꾸고 `node tools/build-sw.mjs`를 실행합니다(테스트가 일치 여부를 검사).
- 차트 색은 `js/charts/theme.js`의 검증된 팔레트(색각 이상 구분·대비 확인)만 사용합니다. 발표 슬라이드 구성 규칙은 `js/present/deck.js`에 있습니다.

### 한글 자동 검증 시 보안 승인 창 없애기 (한컴 공식 보안 모듈)

한글 COM 자동화로 파일을 열면 "한글을 이용하여 위 파일에 접근하려는 시도…" 창이 뜰 수 있습니다. 한컴 공식 **오토메이션 보안 승인 모듈**을 PC마다 한 번 설치하면 뜨지 않습니다(관리자 권한 불필요).

```powershell
powershell -ExecutionPolicy Bypass -File tools/install-hwp-security-module.ps1 -Test   # 설치·등록·동작 확인 (npm run hwp:secmodule)
powershell -ExecutionPolicy Bypass -File tools/install-hwp-security-module.ps1 -ZipPath "보안모듈(Automation).zip"   # 인터넷 차단 PC
powershell -ExecutionPolicy Bypass -File tools/install-hwp-security-module.ps1 -Uninstall   # 제거
```

- 설치 스크립트는 [한컴디벨로퍼](https://developer.hancom.com/hwpautomation) 공식 배포본 `보안모듈(Automation).zip`을 받아 SHA-256과 비트(한글 2024는 32비트)를 확인합니다. 이어서 `%LOCALAPPDATA%\HNC\HwpAutomation\SecurityModule`에 DLL을 복사하고, `HKCU\Software\HNC\HwpAutomation\Modules`에 `FilePathCheckerModuleExample` = DLL 경로를 등록합니다.
- 자동화 코드는 `tools/lib/hwp-com.ps1`의 `New-HwpAutomation`이 파일을 열기 전에 `RegisterModule("FilePathCheckDLL", "FilePathCheckerModuleExample")`를 호출합니다. 두 번째 인자는 레지스트리 값 이름과 같아야 합니다.
- 한컴 예제 모듈은 모든 경로 접근을 허용하며, `RegisterModule`을 호출한 자동화 세션에만 적용됩니다.
