# 청소년 활동·사업 성과지표 고도화 계획 및 구현 추적

기준: 2026-09-24. 대상: 일반 사업 담당자, 청소년지도사, 평가 담당자, 관리자.
사용자 승인 계획을 기준으로 한 구현 추적 문서. 출시 후보: **5.47.0 관리자 검증판**.

## 현재 구현 평가와 기본 결정

착수 당시 분석·보고서 기반은 있었으나 목적 선택은 설명뿐이었고 고정 목표 예시가 실제 목표로 입력되었다. 일부 후속 기능은 플래그만 등록되어 있었다. 안내문·참고자료·일부 품질 경고 구현을 전체 고도화 완료로 간주하지 않는다.

- 첫 질문은 “이번 사업에서 무엇을 확인하려 하나요?”로 한다.
- 목표 달성, 관찰된 변화, 측정의 한계를 구분한다. 목표 없이도 결과를 제공한다.
- 운영 실적과 설문 응답자 수를 구분한다. 만족도는 참여 경험이지 변화 측정 자체가 아니다.
- 공식 문항·연령·규준을 추정하지 않는다. 사용자 도구는 공식 도구로 인증하지 않는다.
- 온라인 설문 수집과 기관 데이터 중앙 수집은 범위에 포함하지 않는다.

## 목표

일반 담당자가 목적을 선택하고 측정 가능한 지표와 근거를 연결하며, 목표 달성과 관찰된 변화를 구분해 보고한다. 브라우저 내 분석을 유지한다. 관리자 검증 후 일반 공개한다.

## 구현 순서

1. 기능 등록 상태 단일화, 미구현 공개 차단, 신규 마이그레이션. 복수 문항 합성·혼합 척도·0/음수 목표·인과 해석 수정.
2. 도구 출처/버전/대상/문항 ID/역채점/점수화 저장. 양방향 누락·중복·척도·버전 검사. 영향받는 지표만 계산 제한.
3. 목적 복수 선택 → 추천 카드 → 목표 없이 측정 또는 목표/근거 입력 → 결과. 카드/표 동일 데이터 편집, 논리모형 접기, 도구 불러오기 미리보기/저장.
4. 역량별 표/그래프·유효 표본·효과크기·주의. 개선 과제/담당자/확인 시점. 화면·HWPX·발표 공통 결과.
5. 로컬 프로젝트 두 개의 버전/대상/척도/점수화/설계/시점 호환성을 확인한 기술적 비교. 순위/전국 규준 추정 금지.

## 호환성·검증

프로젝트 버전업과 이전 파일 변환, 안정적인 문항 참조, 계산 규칙 버전과 변경 안내, 자동 저장·복원·되돌리기·코드북 재적용 검증. 공식 도구와 사용자 수정 도구 구분.

계산 경계값·저장 왕복·카드/표·모바일·키보드·역할/플래그·보고서 일치를 검증한다. 단위 테스트·E2E·보고서 검증・CI・실제 Pages 배포 확인 필요. 버전·릴리스·서비스워커 동기화.

비전문 담당자 5명 중 4명 이상이 도움 없이 완료하는 사용성 검증은 미실시. KYWA 첨부 HWP의 전체 문항·연령 기준·채점·이용 조건 검증도 미완료. 추정하거나 완료로 보고하지 않는다.

## 진행

- 착수: 작업 트리 깨끗함. 후속 4개 기능은 스위치만 있고 미구현임을 확인.
- 5.47.0 구현 및 검증 진행. 아래 완료 근거와 남은 조건을 구분한다. 전체 계획 및 일반 공개 완료를 주장하지 않는다.

### 1단계: 계산·공개 제어

- 상태 목록 `js/admin/feature-status.js`: 개발 예정 / 관리자 검증 / 공개 가능 및 의존성.
- 개발 예정은 관리자도 비활성화. 관리자 검증은 일반 공개 스위치 잠금. 서버 공개값만으로 미완성 기능을 열 수 없음.
- 새 `0010_measurement_features.sql` 시드, `ON CONFLICT DO NOTHING`으로 기존 운영값 보존. 과거 0006에 추가되었던 후속 시드는 분리.
- 응답자별 양 시점 공통 문항의 평균으로 변화·효과크기·향상자 비율 계산. 최소 절반 공통 응답 기준, 혼합 원척도 합산 거부.
- 0·음수 목표는 방향에 따른 충족 여부, 양수 목표는 기존 비율 판정 유지. 목표 미설정과 측정 불가 분리.
- 화면·보고서·발표자료에서 사업 전체의 종합 등급 대신 목표 달성 요약. 일률적 차년도 목표 제안 기본 출력 제외.
- 계산은 권한과 무관하며 공개 플래그·로그아웃 변경 시 보고서 캐시 재계산.

### 2단계: 도구·품질·저장

- 도구 이름/출처/버전/대상/시점, 문항 ID/영역/척도/역채점/정의 스냅샷 저장.
- 사용자 세트 적용 전 이름·시점의 유일한 연결을 확인. 모호하거나 누락된 문항은 적용 거부.
- 사전·사후 양방향 누락, 중복 문항/응답자 연결, 척도·역채점·버전·원본 문항 ID 검사.
- 오류가 있는 문항의 지표와 합성 영역만 제한. 품질 점검을 타당성 인증으로 표현하지 않음.
- 프로젝트 구조 v2 / 계산 규칙 v2를 구분하고 이전 파일에 계산 변경 안내 추가.
- `@item:열키`, `@domain:영역ID` 명시적 참조. 코드북 재적용 시 열키 재연결, 모호한 기존 문항명은 사용자 확인 요구.
- 코드북·프로젝트·내역에 도구와 목적·개선 과제 보존.

### 3단계: 간편 설정

- 운영 규모 / 참여 경험·만족 / 역량·태도 변화 / 후속 실천 복수 선택.
- 목적별 추천 → 카드에서 문항 직접 선택 → 목표 선택 입력 및 실적 확인.
- 신규 간편 지표 목표 미설정, 대상 자동 전체 연결 금지. 기존 표와 카드가 같은 데이터를 편집.
- 카드별 고급 설정, 사업정보·논리모형 접기, 자료 부족 안내.
- 사용자 도구 JSON 내보내기/불러오기 및 XLSX 문항정보 미리보기/적용.
- XLSX 계약: `문항정보` 또는 `코드북` 시트 하나; 필수 열 `문항ID, 문항명, 최소값, 최대값`; 선택 열 `시점, 영역, 역채점`. 임의 HWP 해석은 지원하지 않음.
- 공식 KYWA 연령별 세트는 **개발 예정**. 링크 열람과 사용자 파일 불러오기를 공식 도구 탑재와 혼동하지 않음.

### 4단계: 결과와 개선

- 측정한 영역만 유효 응답자·문항 수·사전/사후·변화량·효과크기 표와 비교 그래프로 제공.
- 도구가 등록된 경우 명시적 합산 허용 없이는 전체 합성점수 생성하지 않음. 기존 도구 미등록 프로젝트의 전체 계산은 호환성 유지.
- `measurement-results.js`가 보고서·발표자료의 공통 결과와 개선 과제를 제공.
- 담당자가 근거·개선 과제·담당자·확인 시점을 작성. 자동 원인 단정 없음.

### 5단계: 기술적 비교

- 현재 프로젝트와 원자료 포함 로컬 프로젝트 하나를 비교.
- 도구 이름·버전·연령군·점수화·시점·조사 설계·문항/영역/척도/역채점/보기점수/결측코드 일치 검사.
- 점수 환산 기준이 다르거나 응답 제외가 적용된 프로젝트는 비교 차단.
- 표본 구성 차이에 대한 주의 표시, 자동 순위·전국 기준·백분위는 제공하지 않음.
- 비교 후 설정이 바뀌면 이전 비교 결과 폐기.

### 후속 구현·검증 과제 (완료로 간주하지 않음)

1. 공식 원문 검증 후 연령별 KYWA 템플릿 등록 및 공식/수정본 식별 정책 검증.
2. 추천 카드별 공식 원문 근거와 적합성 설명 세분화, 진로·동아리·참여·문화예술 설계 사례 확충.
3. 측정도구 개정 이력 비교·편집 시 수정본 판별, 과거 계산 결과 스냅샷과 새 결과의 차이 표시 고도화.
4. 연도 비교의 실제 표본 구성 대조표, 응답 제외 적용 자료 비교, 선택형 레이더 보기.
5. 관리자 실계정·저장 복원·카드/표 키보드 경로 및 신규 보고서 수치 전체 조합 검증 확대.
6. 위 항목과 담당자 사용성 검증 완료 후 해당 기능 상태를 공개 가능으로 승격하고 공개 스위치를 사용.
